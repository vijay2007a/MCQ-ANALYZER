Which of the following architectural patterns best describes a system where the user interface is completely decoupled from the data access layer, communicating solely through a standardized API?

Correct Answer

Microservices Architecture

lightbulb Explanation

In a Microservices Architecture, the system is structured as a collection of loosely coupled services. The UI (often a Single Page Application or mobile app) acts as a separate entity that interacts with these backend services exclusively via well-defined APIs (like REST or GraphQL).

A Monolithic Architecture, which you selected, typically tightly couples the UI rendering logic, business rules, and data access within a single deployable unit, making independent scaling and decoupled deployments difficult.
